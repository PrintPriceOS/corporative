# Comparativas Técnicas y Fuentes Oficiales de Preflight

**Fecha de Revisión y Verificación:** 24 de Octubre de 2026  
**Ámbito de Comparación:** Soluciones líderes de verificación y corrección de artes finales PDF frente a **PrintPrice Preflight**.  
**Criterio Metodológico:** Cada producto y edición se analiza de forma individual según su documentación oficial vigente, sin combinar versiones de escritorio con versiones de servidor en una misma columna.

---

## 1. Fuentes Oficiales Auditadas

1. **Adobe Acrobat Pro (Herramienta Comprobaciones / Preflight)**:
   - *Fuente oficial:* [Adobe Acrobat User Guide — Preflight Profiles](https://helpx.adobe.com/acrobat/using/preflight-profiles-acrobat-pro.html) y [PDF fixups documentation](https://helpx.adobe.com/acrobat/using/correcting-problem-areas-preflight-tool.html).
   - *Edición analizada:* Adobe Acrobat Pro 2024 / Continuous Release (Escritorio).
   - *Enfoque:* Software de edición documental con motor de comprobación técnica integrado (licenciado originalmente por callas software).
2. **Enfocus PitStop Pro**:
   - *Fuente oficial:* [Enfocus PitStop Pro Official Overview](https://www.enfocus.com/es/pitstop-pro) y manual de usuario v2024.
   - *Edición analizada:* Enfocus PitStop Pro 2024 (Plugin para Adobe Acrobat).
   - *Enfoque:* Estación de trabajo para operadores de preimpresión; edición interactiva de vectores, textos, colores y Action Lists.
3. **Enfocus PitStop Server**:
   - *Fuente oficial:* [Enfocus PitStop Server Manuals & Specs](https://www.enfocus.com/en/support/manuals/pitstop-server-manuals).
   - *Edición analizada:* Enfocus PitStop Server 2024.
   - *Enfoque:* Automatización desasistida mediante carpetas calientes (hot folders) y CLI para talleres y plantas de impresión.
4. **callas pdfToolbox Desktop**:
   - *Fuente oficial:* [callas software — pdfToolbox Desktop Product Page](https://callassoftware.com/products/pdftoolbox/) y manuales de referencia técnica.
   - *Edición analizada:* callas pdfToolbox Desktop 14/15.
   - *Enfoque:* Aplicación de escritorio independiente (standalone) para control de calidad, imposición visual y conversión de color con perfiles Ghent Workgroup (GWG).
5. **callas pdfToolbox Server / CLI / SDK**:
   - *Fuente oficial:* [callas software — pdfToolbox Server/CLI/SDK](https://callassoftware.com/products/pdftoolbox-server/).
   - *Edición analizada:* callas pdfToolbox Server / CLI v14/15.
   - *Enfoque:* Motor industrial de alto rendimiento con procesamiento paralelo, API REST, SDK (C++, Java, .NET) y hot folders.
6. **PrintPrice Preflight**:
   - *Fuente oficial:* Código de motor `ppos-preflight-engine` v1.9.0, servicio `ppos-preflight-service` v1.9.0 y documentación en `https://docs.printprice.pro/docs/engines/preflight-engine`.
   - *Edición analizada:* Web SaaS en `https://preflight.printprice.pro/` + Motor distribuido en la nube.
   - *Enfoque:* Servicio de validación técnica determinista, diagnóstico pedagógico para autores/editoriales y enrutamiento con imprentas industriales asociadas.

## 4. Conclusiones Comparativas para Difusión Comercial

1. **PrintPrice Preflight** no pretende competir como un editor gráfico interactivo manual de objetos como PitStop Pro, ni como un motor de hot folders locales para un único taller como pdfToolbox Server.
2. Su propuesta de valor diferencial reside en:
   - **Acceso universal sin fricción:** Cualquier autor o editorial comprueba su PDF al instante desde la web antes de enviar a imprenta.
   - **Diagnóstico inteligible:** Explicación técnica traducida a recomendaciones prácticas.
   - **Conexión inmutable con fabricación:** La validación genera un `evidenceId` que viaja junto con el presupuesto y la orden de producción en el Control Plane, garantizando que el taller imprime exactamente lo validado.
