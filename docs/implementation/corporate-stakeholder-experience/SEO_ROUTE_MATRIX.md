## 2. Mapa de Rutas No Indexables y Protegidas

Las siguientes rutas y prefijos están explícitamente excluidos del sitemap y bloqueados mediante directiva `Disallow` en `app/robots.ts`:

| Prefijo / Ruta | Motivo de Exclusión | Directiva Robots |
|---|---|:---:|
| `/api/*` | Endpoints API de backend y telemetría | `Disallow: /api/` |
| `/debug/*` | Paneles de depuración local y telemetría interna | `Disallow: /debug/` |
| `/admin/*` | Rutas de administración interna | `Disallow: /admin/` |
| `/_not-found` | Ruta interna de fallback de errores 404 en Next.js | `Disallow: /_not-found` |

> [!NOTE]
> La directiva `Allow: /` permite el rastreo general y explícitamente **no bloquea `/_next/` ni ficheros estáticos (`.css`, `.js`, imágenes)**, garantizando que el Googlebot y Bingbot puedan renderizar los estilos y scripts con fidelidad total.
